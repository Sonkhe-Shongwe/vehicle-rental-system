# R2 local Lucide pilot

Nine SVGs from the official [Lucide](https://github.com/lucide-icons/lucide) source pinned at `53fab88ff9d1b48f4704b5b5b560d6b4d560bf4c`, under `icons/<name>.svg`: layout-grid, car-front, clipboard-list, plus, layers, key-round, database, circle-check, chevron-right. These are equivalent SVG geometry derivatives: original path, rect, circle, ellipse data preserved, viewBox 24, stroke 2, round joins/caps. Their markup is normalized to a single SVG line and `currentColor` is replaced with static tone values: active #0B4B3D, inverse #F7FAF9 and emerald #0F766E. The complete upstream ISC and inherited Feather MIT notice is in LICENSE-LUCIDE.txt. They are embedded offline as Qt resources, not fetched at runtime. Custom Rental Studio brand remains unchanged; this pilot does not migrate other icon controls. Native Linux/Windows Qt SVG and accessibility verification are required.
