# Rental Studio 2.0 | Free model-photo catalogue acquisition, Batch 05

**Source selection date:** 5 November 2026. **Target:** ten previously unsourced proposed models, including luxury SUVs, a popular hatchback, a budget hatchback and a bakkie.

All original Commons File: names are pinned individually in `sources.json`. The GitHub acquisition workflow will independently verify source name, Creative Commons CC0 / CC BY / CC BY-SA free licence, photographer, canonical original page and official Wikimedia asset URL. Verified photographs are resized and letterboxed without distortion, then stored as 1024×680 JPEGs, with per-file SHA256 and credit records. The contact sheet is created only from the checked saved files.

**At this commit, sources are nominated but not yet downloaded.** Workflow completion is necessary before adding them to the "acquired" total. Download and licensing checks do not equal visual approval.

**No integration in this batch:** images remain in `catalogue_acquisition/batch05/`, not in `assets/portfolio/`. No Fleet QML/C++/CMake change, no paid service, no operational database or customer data, no release, no protected main change. Free offline portfolio only.
