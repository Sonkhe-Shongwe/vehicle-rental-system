# Rental Studio 2.0 | Free model-matched vehicle photos, Batch 02

**Status:** ten sources selected. Image acquisition, licence checks, downloaded files, hashes and visual approval are **pending the new batch workflow**.

This second batch targets **eight existing wrong-model images** (Suzuki Jimny, Chery Tiggo 4, Jeep Wrangler, Volkswagen Caddy, Nissan Almera, Toyota Starlet, Mercedes-Benz C-Class and Ford EcoSport), plus **two proposed showcase models** (BMW M4 and Audi RS6 Avant).

Method: individually nominated Wikimedia Commons `File:` pages, official MediaWiki API metadata and photo endpoints, acceptable free CC0/CC BY/CC BY-SA licensing, source/author credits, resized offline JPEGs, SHA256 and verified contact sheet. Any missing or incompatible image fails the batch rather than silently associating the wrong car.

**Separation:** files in this folder are not compiled into Qt and have not changed Fleet. No production data, paid API or main-branch change.
