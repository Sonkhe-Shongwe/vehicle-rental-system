# Rental Studio portfolio image acquisition | Batch 04

**Research target:** ten new proposed models spanning performance, SUV and EV types. The ten specific Wikimedia Commons file titles appear in `sources.json`; none is an automated search result substituted into a different model.

**Source verification:** use the free official MediaWiki API to check exact file identity, permitted CC0 / CC BY / CC BY-SA licence, author and source URL. Download only verified HTTPS Wikimedia media, optimize to 1024 × 680 offline JPEG without stretching, save individual image credits, source metadata and SHA256, and create an audited contact sheet.

**Important:** at this source-selection commit the actual files have not yet been downloaded or accepted. The workflow must complete successfully to count them as acquired. Afterwards they remain **staged research**, not an automatic update to the Fleet gallery, CMake resources, historical five-vehicle fixtures or actual 100-unit demo.

This is a free offline portfolio project. No paid subscriptions, personal data, production P7 SQLite, application release, or changes to stable main.
